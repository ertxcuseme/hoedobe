Autosave

Hoedobe keeps a draft of your work inside this browser while you edit, so a crash, power cut or closed tab doesn't lose it. When you open Hoedobe again, it offers to restore.

On Chrome or Edge on a computer, it can also keep rolling backup files in a folder you choose. Each file is a normal PDF that also remembers your edits, so reopening one lets you keep editing and undo.

Files are named like 26Y10M16T2026-Medium.pdf. It keeps up to 10 per PDF per day: the newest, the one before it, then older ones about 5 minutes apart, reaching back about an hour.

This browser can't write files to a folder by itself. Use Save PDF to put a copy in Files or Downloads.

Revert to the original?

This removes every edit you made, on every page, and shows the PDF as it was when you opened it.

It isn't permanent. Undo (Ctrl+Z) brings every edit back.
